# Safety

Memory changes preference, never authority.

| Class | Default |
|---|---|
| Safe observation | May run automatically |
| Reversible mitigation | Policy-dependent |
| High-risk change | Human approval required |
| Destructive action | Human approval required |

The action catalog owns risk classification. Retrieved memories cannot rewrite or lower it. The first release executes no real infrastructure commands; all telemetry, approvals, mitigations, and outcomes are visibly simulated.

Storage or search failure enters degraded mode, returns no memory evidence, and preserves the baseline safety policy. Base rejection, wrong network/contract, failed transactions, and hash mismatches remain unverified. Operator feedback is contextual evidence with confidence/reuse metadata, not universal truth.
