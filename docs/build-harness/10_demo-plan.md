# Demo plan

Demo thesis: in under 90 seconds, prove a fresh process avoids a known failed mitigation only because Sibyl retrieves Session A.

1. Open the one public Vercel URL.
2. Run Session A; show baseline restart, bad outcome, Sibyl record, and confirmed process exit.
3. Refresh the page; show the record restored.
4. Run Session B; show a different session ID and PID.
5. Show the retrieved Session A memory and the decision change.
6. Open View Proof and show policy plus Base status.
7. If anchored, open the Base Sepolia explorer receipt; otherwise say UNANCHORED.

Backup: use a recording of a previously captured REAL public execution, clearly labeled as recorded.
