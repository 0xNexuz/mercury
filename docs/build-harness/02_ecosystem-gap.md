# Ecosystem gap

Sibyl provides local-first structured memory and Base provides public transaction provenance, but an inspectable incident-response workflow connecting durable experience, deterministic influence, safety policy, and privacy-preserving receipts is not otherwise supplied by this repository's dependencies.

Sibyl is load-bearing: removing retrieval restores the baseline action. Base is independently valuable provenance: removing it leaves memory behavior intact but removes third-party timestamped commitment evidence.

The reusable gap is an auditable memory-to-decision trace, not another generic incident dashboard.
